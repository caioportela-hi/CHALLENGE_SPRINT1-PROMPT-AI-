# CHALLENGE_SPRINT1-PROMPT-AI-
Repositório criado com o intuito de documentar os procedimentos para a confecção de um chatbot destinado à resolver um problema enfrentado pela GoodWe.

## ChargeGrid Intelligence Bot

# Sobre o Desafio

O EV Challenge 2026 proposto pela GoodWe apresenta um problema real enfrentado por operadores de eletropostos comerciais: a ausência de mecanismos integrados para orquestrar
potência, registrar ciclos de recarga, processar faturamento e comunicar status dos equipamentos - o que a GoodWe denomina ChargeGrid Intelligence.
Atualmente, operadores precisam acessar múltiplos painéis e ferramentas desconexas para obter informações básicas sobre seus postos. Não há um ponto único de consulta
inteligente que contextualize os dados operacionais.
